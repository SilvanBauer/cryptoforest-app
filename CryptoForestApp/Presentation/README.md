# Presentation
Contains all views displayed and used in the application. All views were created with MVUX + XAML.
The Shell UserControl was generated by Uno Platform.

## Dialogs
Contains all `ContentDialog`s of the application. Basic text based dialogs were created with the `INavigator` in their respective pages.

## Pages
Contains all pages displayed in the application. The default page visible on startup is currtently the `HistoryPage`.
