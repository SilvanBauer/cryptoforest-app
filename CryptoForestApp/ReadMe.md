# Cryptograph Forest desktop application
![2025_007_CryptoForest_Logo](https://github.com/user-attachments/assets/1688ccd6-e20e-4c0d-b518-2d1edd3a9e07)

## What is it?
The Cryptograph Forest desktop application allows users to use the an easy to use solution for securly storing data and text in multiple levels in a tree structure.

The application currently runs on Windows and Linux (technically Mac OS is also supported but not tested so no guarantees that it works as expected) and is translated to english and german.

## Quick guide
### Creating & opening a CryptoForest
On the history page it is possible to create a new CryptoForest with the 'Create' button. Once the directory is selected the CryptoForest is automatically created and ready to use.

After the CryptoForest is open the 'Export' button allows to export an encrypted configuration containing the selected levels. The exported configuration is used when opening the CryptoForest again from the history page with the 'Open' button.

### Encrypting, decrypting and managing data
Once a CryptoForest is open it is possible to add new data with the 'Add' button. There are three types of data: Text, Files and Directory. With the 'Add level' button it is possible to create another level.
With the 'Delete' button it is possible to delete the selected item. The delete operation is possible on data as well as on levels. With the 'Move' button a data item can be moved from one level to another one. Levels cannot be moved.

To decrypt the data again it is possible to select the item and use the 'Decrypt' button.

### Navigating
You can enter a level item by performing a double click on it. To go one level up the '..' level item can be used. With the back '\<' and forward '\>' buttons it is possible to go through the history.
With the 'Search' button a search query can be performed on the whole level structure. With the 'Reset' button the query can be reset and the base level is displayed again.
