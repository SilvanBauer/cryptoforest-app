# Models
Contains the DTO and other records needed throughout the application. The `ValueText\<T\>` was introduced to have a simple record for datasources used by elements like ComboBoxes.
The `AppConfig` record was generated by Uno Platform and is currently not used but could be used in the future to store a configuration that the user is able to adjust to their liking.

# Dtos
To be able to pass data from one page to another one we need entities containing the data.
So for each page and content dialog a DTO was created. A DTO was also created if there already was an existing one that had the exact same data because in the future it might be that a page needs additional data.
