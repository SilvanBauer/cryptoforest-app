# Add data page
This page let's you add a new text or data item to the CryptoForest.

The first thing you need to select is the type of the data to add. There are three types:
- Files: One or multiple files which will be added to the same data item
- Directory: A whole directory including the whole directory structure which will be added to the same data item
- Text: A one line text which will be added to the text item

Afterward the data needs to be selected / entered. For files a file selector will open which let's you select multiple files. For directory a directory selector will open which let's you select exactly one directory. And for text a textbox will be displayed where you can enter your one line text.

Next the level this data should be added to can be selected. The level displayed in the main page after opening is called the base level.

Lastly you will need to give a name to the new item. No other data / text item in the same level should have the same name.

With the 'Add' button the data will be encrypted and a new data or text item is added to the selected level. Should any input be missing something a pop-up will be displayed. Once the item has been added you will automatically be redirected to the [Main page](Main.md). You can also get back to the [Main page](Main.md) at any time by clicking the back button. All entered data will be lost if the back button is used.
