# Open page
The open page is used to open an existing CryptoForest. On this page you will need to select the cfc (Cryptograph Forest Config) file exported in a previous session. To select the cfc file you can use de 'Select' button besides the disabled textbox.

Otherwise only the same password used when exporting the config needs to be entered.

With the 'Open' button the CryptoForest can be opened and you will be displayed with the [Main page](Main.md). Should the cfc file be invalid or the password be wrong this operation will fail.

With the 'Back' button you will get back to the [History screen](History.md).
