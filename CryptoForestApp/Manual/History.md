# History page
When application is started the first screen you will see is the 'History' page. In this page all paths which were used to open or create a CryptoForest are displayed in order of when they were last used.

- To open an existing CryptoForest in a path already displayed in the history you need to select the entry (thee selected entry is highlighted by the blue background color) and click on 'Open'. Afterward the [Open page](Open.md) is displayed.
- The 'Add' button can be used to add a new path of an existing CryptoForest. After clicking on 'Add' a selector opens which allows you to select a directory which should be added to the history. Once in the history the 'Open' button can be used to open it.
- To create a new CryptoForest 'Create' can be used. After clicking on 'Create' you are presented with a selector for a directory. If the directory is not empty you will need to confirm that you really want to create the CryptoForest there. After the CryptoForest is created it will be automatically opend and you will see the [Main screen](Main.md).

You can close the application with the 'Cancel' button.
