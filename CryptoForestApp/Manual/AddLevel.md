# Add level page
This page let's you add a new level to the CryptoForest.

The first thing you need to select is the parent level. The level displayed in the main page after opening is called the base level.

Afterward you can enter a name for the level. No other level on the same parent level can exist with the same name.

With the 'Add' button the level will be added. Should any input be missing something a pop-up will be displayed. Once the level has been added you will automatically be redirected to the [Main page](Main.md). You can also get back to the [Main page](Main.md) at any time by clicking the back button. All entered data will be lost if the back button is used.
